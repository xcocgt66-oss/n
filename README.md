# بروكسي تيوب (YouTube HTTPS Proxy for Vercel)

مشروع موقع ويب كامل للبحث وتشغيل مقاطع يوتيوب بالكامل عبر سيرفر **Vercel** باستخدام **HTTPS فقط** (بدون WebSockets وبدون أي API مدفوع).

## المميزات
- **إخفاء كامل لاتصال المستخدم عن يوتيوب**: البحث (`/api/search`)، الصور المصغرة (`/api/thumb`)، وبث الفيديو (`/api/stream`) تمر كلها عبر سيرفر Vercel.
- **بروتوكول HTTPS فقط**: لا يستخدم WebSockets نهائياً.
- **تجاوز حد 4.5MB في Vercel**: يعتمد `/api/stream` على تقسيم البث عبر `HTTP 206 Partial Content` (حجم كل قطعة 2MB)، ما يسمح بتشغيل مقاطع طويلة والتقديم/التأخير بسلاسة.
- **محرك بدائل تلقائي (Fallback)**: يحاول السحب من YouTube Innertube مباشرة، وفي حال وجود تقييد على IP السيرفر ينتقل تلقائياً إلى سيرفرات Piped و Invidious العامة، مع إمكانية إضافة سيرفر مخصص من الإعدادات داخل الموقع.

## طريقة الرفع والتشغيل على Vercel (مجاناً)
1. فك الضغط عن الملف.
2. أنشئ مستودعاً (Repository) جديداً في **GitHub** وارفع بداخله الملفات والمجلدات (`public` و `api` و `lib` و `package.json` و `vercel.json`).
3. ادخل على **Vercel** -> اضغط **Add New Project** -> اختر المستودع من GitHub.
4. اضغط **Deploy** مباشرة بدون تغيير أي إعدادات.
5. بعد ثوانٍ سيعطيك Vercel رابط `https://...vercel.app` جاهز للاستخدام.

## متغيرات بيئة اختيارية في Vercel (Environment Variables)
في حال أردت تثبيت سيرفر بديل لجميع المستخدمين يمكنك إضافتها من إعدادات المشروع في Vercel:
- `CUSTOM_PIPED_API`: رابط Piped API مخصص.
- `CUSTOM_INVIDIOUS_API`: رابط Invidious API مخصص.
- `YT_COOKIE`: كوكيز يوتيوب (اختياري في حال شدد يوتيوب الحماية على IP السيرفر).
